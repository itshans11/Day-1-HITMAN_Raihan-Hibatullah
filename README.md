Deskripsi singkat mengenai repository
Repository adalah tempat penyimpanan digital yang digunakan untuk menyimpan, mengelola, dan mengorganisasi berbagai file atau kode program dalam suatu proyek. Repository biasanya digunakan oleh pengembang untuk menyimpan dokumentasi, kode sumber (source code), serta file pendukung lainnya. Salah satu platform yang menyediakan layanan repository adalah GitHub.

Tujuan atau kegunaan repository.
1. Menyimpan file proyek: Menyimpan kode program, dokumen, gambar, dan file pendukung lainnya dalam satu tempat.
2. Mengelola perubahan: Mencatat setiap perubahan pada file sehingga pengguna dapat melihat riwayat perubahan sebelumnya.
3. Mempermudah kolaborasi: Memungkinkan beberapa orang bekerja sama dalam satu proyek.
4. Menjaga keamanan data: Membantu menyimpan salinan proyek sehingga risiko kehilangan data dapat dikurangi.
5. Memudahkan pengembangan proyek: Mempermudah pengguna dalam memperbaiki, memperbarui, dan mengembangkan proyek.
